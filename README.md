# greet

A tiny Python greeting utility — my first project built together with Claude Code.

## Usage

```bash
python greet.py "Sho"
# => Hello, Sho!
```

If you don't pass a name, it greets the whole world:

```bash
python greet.py
# => Hello, world!
```

## Running the tests

```bash
python -m pytest
```
